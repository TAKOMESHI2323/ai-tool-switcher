# AI Tool Switcher

AI開発ツールを1クリックで起動・前面表示する、HoshiLaboのmacOS用ランチャーです。アイコンだけの小さなパネルを画面上に置いて、複数のAIツールを切り替えられます。

## 対象

- Antigravity
- Antigravity IDE
- Claudeデスクトップアプリ（パネル表示は「ClaudeCode」）
- Gemini
- Grok Bot
- Codex（ChatGPT/Codexアプリ、またはTerminal系）
- Cursor

アイコンはインストール済みのアプリから取得します。取得できない場合はmacOSのシンボルが表示されます。未起動のツールはグレー、起動中はカラーです。マウスを重ねるとツール名と起動状態を確認できます。矢印ボタンで縦型と横型を切り替えられます。

## 作業状態バッジ

アイコンを右クリックして「作業中」または「作業終了」を手動で設定できます。完了のチェックは、アイコンをクリックするか「確認済みにする（バッジを消す）」を選ぶまで表示されます。未確認の完了チェックとパネルの向きは、次回起動時にも引き継がれます。

## 動作環境

- Apple Silicon搭載Mac、macOS 14以降
- ビルドにはSwift 6以降とmacOS SDKが必要です。対応するXcodeまたはCommand Line Toolsをインストールしてください。
- 切り替えたいアプリは別途インストールしてください。

## ビルドと起動

ターミナルでこのリポジトリのルートを開き、次を実行します。

```bash
zsh Scripts/build-app.sh
open "build/AI Tool Switcher.app"
```

テストには **Xcode** の開発ツールを選択し、同じディレクトリで `swift test` を実行します。

## アクセシビリティ権限

ウインドウ名を見て対象のウインドウを前面に出すには、「システム設定」→「プライバシーとセキュリティ」→「アクセシビリティ」で **AI Tool Switcher** を許可してください。許可しない場合は、アプリ単位で前面化を試みます。Codexボタンはデスクトップアプリに加え、Terminalなども切り替え先の候補にします。

各アプリの名称は切り替え先を示すもので、AI Tool SwitcherはHoshiLaboが開発しています。
